# Для тебя — сайт-подарок

Атмосферная одностраничная история для QR-кода в открытке. Полностью статичный сайт: HTML + CSS + JS, без бэкенда.

## Структура проекта

```
index.html   — весь сайт целиком: разметка, стили и логика в одном файле
images/      — сюда кладёте свои фотографии (01.jpg ... 10.jpg)
music/       — сюда кладёте mp3 песни (song.mp3)
```

Всё, кроме фотографий и музыки, объединено в один файл `index.html` — так проще
загружать и редактировать. CSS лежит внутри тега `<style>` в начале файла,
JS — внутри тега `<script>` в конце файла.

## Что нужно заменить перед публикацией

1. **Фотографии** — папка `images/`, инструкция внутри неё в файле `ПРОЧТИ_МЕНЯ.txt`.
2. **Музыка** — папка `music/`, инструкция внутри неё, либо просто откройте
   `index.html`, найдите в конце файла (в теге `<script>`) блок `CONFIG`
   и поменяйте `musicSrc` на прямую ссылку на mp3.
3. **Тексты и подписи под фото** — в `index.html`, в блоке `<main class="story">`,
   у каждого `<section class="frame">` есть строка `<p class="frame-caption">...</p>` — меняйте текст там.
4. **Заголовок обложки и финальный текст** — тоже в `index.html`, в блоках
   `<section class="intro">` и `<section class="finale">`.

Все места для правок явно прокомментированы прямо в файле.

## Как посмотреть локально

Просто откройте `index.html` в браузере. Для корректной работы автозапуска
музыки при последующих открытиях лучше запускать через локальный сервер, например:

```
npx serve .
```

или в Python:

```
python3 -m http.server 8080
```

и открыть `http://localhost:8080`.

## Как опубликовать бесплатно

### Вариант 1 — GitHub Pages (самый простой)
1. Создайте новый репозиторий на GitHub и загрузите в него все файлы проекта
   (`index.html`, `style.css`, `script.js`, папки `images/` и `music/`).
2. Зайдите в **Settings → Pages**.
3. В разделе **Source** выберите ветку `main` и папку `/root`, сохраните.
4. Через 1–2 минуты сайт будет доступен по ссылке вида
   `https://ваш-логин.github.io/название-репозитория/`.

### Вариант 2 — Cloudflare Pages
1. Зайдите на pages.cloudflare.com → **Create a project** → **Upload assets**.
2. Перетащите папку проекта целиком (или загрузите zip).
3. Cloudflare выдаст готовую HTTPS-ссылку вида `https://ваш-проект.pages.dev`.

### Вариант 3 — Vercel
1. Зайдите на vercel.com → **Add New… → Project**.
2. Загрузите папку проекта (можно перетащить в интерфейс, без Git).
3. Оставьте настройки по умолчанию (Framework: Other) и нажмите **Deploy**.
4. Получите ссылку вида `https://ваш-проект.vercel.app`.

Домен покупать не нужно — во всех трёх вариантах вы получаете готовую бесплатную HTTPS-ссылку.

## Как сделать QR-код

Возьмите готовую опубликованную ссылку и вставьте в любой бесплатный
генератор QR-кодов (например, qr-code-generator.com или встроенный в
Google Chrome — значок «поделиться» → «QR-код страницы»). Распечатайте
и вклейте в открытку.

## Технические детали

- Музыка не запускается автоматически при заходе на сайт — только
  по нажатию кнопки «Открыть наше воспоминание», как того требуют
  правила мобильных браузеров (и iPhone Safari в частности).
- Появление фотографий и подписей построено на `IntersectionObserver` —
  лёгкая, плавная и не нагружающая телефон анимация без внешних библиотек.
- Никаких сторонних JS-фреймворков — чистый HTML/CSS/JS, поэтому сайт
  быстро грузится даже на медленном мобильном интернете.
- Заглушки: пока настоящие фото не добавлены, вместо них показываются
  аккуратные тёмные плейсхолдеры — сайт не «ломается» и выглядит цельно.
